# 援来有路：人员搜索、主动确认与物资投送算法方案

本方案是待验证的研究设计，附 Webots R2025a 原型。不能据此宣称算法已创新、已优于基线或已适用于真实灾害。主线选两项：①面向有效人员报告的搜索—确认—投送滚动调度；②定位不确定性约束的主动多视角确认。检测、里程计、局部避障作为共用支撑模块，不再同时引入强化学习，以免无法归因。

本文件是研究设计与待验证假设；当前仓库的准确运行入口、实现范围和限制见 [SEARCH_ALGORITHMS.md](SEARCH_ALGORITHMS.md)。当前实现采用启发式收益/耗时模型，尚未完成概率标定和正式对比。

## 1. 暂定任务条件与边界

以下全部是暂定条件，需根据实车、赛题和实验调整：单台差速无人车；360°激光雷达与对齐 RGB-D；轮速编码器、带噪 IMU 提供运动估计；无 GPS、无预知人员坐标。任务区外边界和出发补给点可知，内部道路、障碍和人员位置未知。当前原型的局部坐标系以出发姿态为原点；报告提供局部坐标、协方差、时间戳、证据图。对外报告地理坐标还需要独立标定的坐标变换，不读取仿真真值实现。

暂定每车携带2份物资，物资站补给6秒；靠近已报告目标安全停稳2秒执行投送事件。原型不模拟机械臂、人与车的物资交接和水动力。距离预算80m仅为能耗代理；不能称为真实续航模型。示例任务投送期限为报告后120秒，smoke 功能场景为35秒；它是统一的任务时限，不代表医学分诊结论。

运动层只采用滚动局部窗口和动态窗口式速度采样，不使用全局最短路径、预先给定路线或真实目标坐标。会有局部极小与死胡同失败，应记录，不能通过隐藏全局规划规避。

## 3. 完整流程

```text
LiDAR / RGB-D / 编码器 / IMU
  → 运动估计 + 在线占据图 + 局部可通行性
  → 图像人员候选 + 深度定位 + 去重目标轨迹
  → 改进②：提出确认位姿、朝向、预计定位收益与耗时
  → 改进①：比较探索 / 确认 / 投送 / 补给 / 返回
  → 局部窗口速度采样执行
  → 独立观测累积 → 合格报告 → 投送任务入队
  → 每轮重估与重调度
独立Supervisor：只评价，不把真值反馈给无人车
```

## 4. 改进一：面向有效报告的滚动任务调度

### 4.1 解决的问题

覆盖面积大不等于找到人多。可能出现快速扫过房屋背面却未拍到人员、围绕同一候选重复观察、确认一半又去探索、发现人员后一直探索而错过投送。优化对象应从未知栅格数量转为“在任务期限内形成可用的新人员报告，并完成承诺投送”。

输入：在线占据图M、位姿及协方差、未报告人员空间强度λ、候选目标信念、改进二的确认动作及预计耗时、已报告投送任务、载荷、预算、当前时间。输出：下一动作类型、局部目标位姿(x,y,θ)、服务对象、计划重估原因。

λ_i表示栅格内尚未报告人员的期望数量，不是把多个可能同时有人栅格强制归一化为一个目标。无可靠先验时用均匀弱先验；只有实际观测到的图像线索可提升局部信念。可验证的语义先验（例如建筑入口周围）必须来自在线观测或独立训练集，不得从测试人员布置反推。

### 4.2 核心机制与公式

将探索动作定义为有朝向的扫描位姿a=(x,y,θ)，而不是一个前沿点。其期望新报告收益为：

\[
G_R(a)=\sum_{i\in FOV(a)}\lambda_i P_{vis}(i|M,a)P_{det}(i|a)P_{pass}(i|a,\Sigma_x,\mathcal B).
\]

P_pass表示经过后续确认可满足报告门限的概率，不能与检测分数混同。多动作序列对重复观察区域去重，防止同一区域收益反复计数。成功未见人的观测可用Poisson稀疏化近似 λ_i←λ_i(1−P_visP_det)；遮挡或低质量观测不能将“没看见”当作“没有人”。

动作集：探索、确认、投送、补给、返回。以2步、约50秒滚动时域为起点，使用分层目标：

\[
\pi^*=\operatorname{lexmin}_{\pi\in\mathcal F}
\left(N_{late}(\pi),\;-\mathbb E[N_{new\ valid}(\pi)],\;T(\pi),\;R(\pi)\right).
\]

先保证已接受投送任务的时限可行性，再比较有效报告收益，最后比较耗时和风险。候选动作必须满足剩余载荷非负、补给服务时间、可通行性、返回储备等约束。正式方案对行程时间使用上分位估计：

\[
\Pr(T_{arr,j}+s_j\le d_j)\ge1-\delta,
\qquad \hat E(\pi)+E_{return}+E_{reserve}\le E_{remain}.
\]

这是规划层的建议模型。当前原型只有“1.35×欧氏距离/名义速度”的时间估计、距离预算和临期抢占，并非已校准的机会约束求解器；不能把这部分称为精确随机优化。后续用开发场景拟合地形相关行程时间分位数、用在线遮挡检测标定P_pass，并以任务指标检验，而不是单纯调权重。

```python
while mission_active:
    update_map_pose_and_tracks()
    confirmation_actions = active_views(unconfirmed_tracks)
    actions = frontiers_with_headings() + confirmation_actions
    actions += pending_deliveries() + reload_and_return()
    feasible = enforce_payload_return_reserve_and_local_safety(actions)
    sequences = enumerate_short_horizon(feasible, depth=2)
    for sequence in sequences:
        predict_arrival_times_and_payload(sequence)
        score = (late_jobs, -deduplicated_expected_valid_reports,
                 execution_time, risk)
    execute_first_action(min_lexicographic(sequences))
    replan_on_new_evidence_or_timeout_or_urgent_delivery()
```

要检验的假设：该机制能否在投送占用搜索时间时维持较多有效报告，并减少超时；也可能因保守投送牺牲搜索，应允许实验出现这一结果。

## 5. 改进二：不确定性约束的主动多视角确认与定位

### 5.1 解决的问题

灾后遮挡目标可能只露出局部身体。单帧框中心深度可能取到墙面，连续相邻帧高度相关；仅提高检测阈值不能解决位置偏差。要选择能看清目标、产生有效新几何信息且车能到达的位置及朝向。

输入：候选目标均值μ、协方差Σ、存在性信念q、观测位姿分组、图像证据、深度有效率、在线障碍图、当前车位姿与运动预算。输出：确认位姿列表、对应朝向、预计可见率、预计定位协方差、预计耗时；合格时输出报告或证据不足时继续观察/降级候选。

### 5.2 定位、相关性与报告门限

对检测实例内部有效深度做鲁棒中位数与离群过滤，不直接取整个框背景：

\[
\hat p_W=T_{WB}T_{BC}\left[dK^{-1}(u,v,1)^T\right],
\quad\Sigma_p=J_z\Sigma_zJ_z^T+J_x\Sigma_xJ_x^T+\Sigma_{bias}.
\]

协方差包含像素、深度、车体位姿和遮挡系统偏差；在山地需完整相机姿态/外参，不把倾斜相机当水平相机。当前投影已补偿安装俯角和IMU横滚/俯仰，地图与运动估计仍为二维，噪声模型简化；正式实验前必须校准相机内外参和误差覆盖率。没有有效深度则保留方位候选，不能伪造距离。

不同帧观测可能共享定位误差。原型采用CI保守融合：

\[
\Sigma_f^{-1}=\omega\Sigma_1^{-1}+(1-\omega)\Sigma_2^{-1},
\quad\mu_f=\Sigma_f\big[\omega\Sigma_1^{-1}\mu_1+(1-\omega)\Sigma_2^{-1}\mu_2\big].
\]

在ω候选上最小化logdetΣ_f。它是已有估计工具，不能消除错误数据关联或模型偏差。目标关联用马氏距离门限和空间门限；正式方案需一对一关联、轨迹合并与重复报告抑制。当前仓库原型已使用一对一关联与距离去重，但未完成外观重识别，仍可能发生轨迹碎片、误合并和误报。

有效观测分组暂定要求与已有组间位移≥0.5m且目标方位差≥12°。这是几何多样性启发式，不是统计独立证明。相邻重复帧不能反复提高q；正式q应以开发集标定的似然比/相关性修正更新，不能把检测置信分数直接当真实概率。

暂定报告判据：

\[
q\ge0.90,\quad n_{groups}\ge2,\quad
\sqrt{5.991\lambda_{max}(\Sigma_{xy})}\le0.80m,
\quad\text{证据有效且未重复报告}.
\]

这里的0.8m是系统自估置信半径；评价真值匹配阈值1m是另一件事。需同时报告95%置信椭圆的实际覆盖率，防止通过虚假缩小协方差提高合格率。原型q更新为固定似然倍率4，只用于流程联调，未标定。

### 5.3 主动位姿与朝向

在目标当前估计周围生成可行圆弧位姿，半径示例1.25、1.9、2.6m，每圈16个方位；未知/高风险/车宽不足的位姿不候选。朝向指向目标不确定区域中心，并留出画面边缘裕度。对目标估计范围进行多射线可见性预测，避免只看中心点。

\[
V(a)=P_{vis}(a)P_{new\ group}(a)
\frac{\eta+\log\det\Sigma-\log\det\hat\Sigma(a)}
{T_{move}(a)+T_{observe}(a)+\epsilon}.
\]

正式版本还应显式模拟是否跨过报告门限，输出P_pass和预计确认时间给改进一；不要只把V分数当作可验证的成功概率。原型使用二维可见率、简化深度噪声和几何分组评分，不具备人体关键点完整度预测。

```python
for candidate in detected_candidates:
    robust_rgbd_localize(candidate)
    associate_and_conservatively_fuse(candidate)
    if new_view_group(candidate):
        update_existence_evidence(candidate)
    if calibrated_report_gate(candidate) and not_duplicate(candidate):
        emit_report(mean, covariance, timestamp, images)
    else:
        poses = sample_safe_target_centric_arcs(candidate)
        for pose in poses:
            predict_occlusion_fov_uncertainty_and_time(pose)
        offer_best_confirmation_actions_to_scheduler()
```

超时或局部不可达时降低该确认任务优先级并记录失败，不让车无限绕同一障碍。人员被完全埋住、无任何可见部分时，本传感配置无法承诺发现，应作为能力边界。

## 6. 两项改进如何闭环

改进一决定“现在去哪里、做什么”；改进二决定“如何把可疑目标变成可靠报告”。例如：探索时看见废墟后蓝色衣物，形成低置信候选；改进二提出侧移1m、转向目标的确认动作与耗时；改进一比较此确认、继续搜索和已报告任务投送时限；执行侧移后通过第二观测组上报，立刻新增投送任务；载荷不足则比较补给与搜索的期限影响。所有计划只使用已观测信念，不能提前使用目标真实坐标。

## 7. Webots实施与当前代码边界

1. 固定R2025a与Python依赖，先复用现有山洪、坍塌房屋、瓦砾地形，保持地图与纹理可追溯。派生场景为A、B、C和smoke：A/B/C保留当前仓库原人物和地形；smoke是独立平地流程夹具。
2. ResearchRover增加360°三线LiDAR、320×240 RGB与同位姿深度相机、轮编码器和带噪IMU。各算法完全共用PROTO和检测条件。
3. 用Robot控制器读取传感器。原型为轮速/IMU/局部扫描匹配，无闭环SLAM；长距离定位漂移和山地投影偏差需先量化。不能宣称已完成高精SLAM。
4. OccupancyMap维护0.18m占据栅格和净空图；低障碍从RGB-D补充；局部2m窗口引导速度采样，预测1.8秒，最高0.18m/s。无全局路径搜索。
5. 接入TrackManager、主动观测候选和MissionScheduler。保存动作、估计位姿、报告图、协方差、物资事件；失败和无效报告都保留。
6. 独立Supervisor读取真实位姿、目标与接触，仅记录评价；控制器不导入Supervisor、不读取evaluation目录、不调用Camera recognition。真实目标在world中渲染是仿真必要条件，不等于给控制器目标坐标。
7. 先跑功能预检，再冻结检测模型、配置、世界和种子，开展配对实验。调参预检不能充当最终对比实验。

代码对应：mapping.py运动估计/地图/局部控制；perception.py候选/定位/CI/分组/NBV；mission.py两步调度与基线开关；search_agent.py闭环；mission_referee.py独立评价；tools/run_search.py单次运行；tools/run_search_matrix.py批量运行；tools/analyze_search_runs.py导出逐次指标CSV。

关键检测限制：默认yolo为上游YOLO11n person检测接口，使用四个图像方向并合并框；开发探测中A/C人物细节图在部分方向检出，B细节图仍漏检。这不是准确率实验。surrogate_rgbd为单独可选的蓝色区域与尺寸候选器，只用于独立平地夹具的流程联调，不代表真实人员识别。正式实验必须先完成多姿态、遮挡、泥污图像标注和检测器标定，按布局拆分数据并冻结权重；所有对照组共用同一模式。模型与权重不是本项目自研。

## 8. 典型灾后工况

| 工况 | 变量 | 主要检验 |
|---|---|---|
| 坍塌房屋与瓦砾遮挡 | 人体可见比例分层：>70%、30–70%、<30%；无遮挡作控制 | 主动侧移是否确实改善确认与定位 |
| 山洪冲毁通道 | 静态积水、泥地、窄口、绕行、死胡同；保证一部分可达任务 | 局部规划失败与行程时间模型误差 |
| 多人员与载荷冲突 | 2–5人、载荷1/2、报告后任务时限60/120/180s | 搜索/确认/补给/投送协调 |
| 误导物与深度失效 | 蓝色杂物、人体海报/假人、相似纹理、深度掉点与反射 | 误报抑制及协方差可信度 |
| 跨场景 | 不同房屋/地形/光照/服装/人物姿态 | 过拟合与泛化边界 |

现有A/B/C三个实例和一个独立平地夹具用于预检，尚不是足够的统计测试集。正式建议10个独立开发布局、至少20个未见测试布局，布局改变目标、遮挡与通道，不仅改变传感噪声种子；每布局3次噪声重复。所有方法共享同一布局及噪声设定，固定仿真时间600秒（另报300秒），速度/传感条件不变。实际统计功效应由开发集方差估计决定。

记录所有人员分母和预先定义的可达/可观测子集分母，不事后删除难例。可观测性筛选可以由离线真值评价完成，但不得输入策略；不可达任务需单独报告，不悄悄算成功。

## 9. 基线与消融

| 方法名/命令参数 | 有效报告调度 | 主动观测 | 说明 |
|---|---|---|---|
| frontier | 否 | 否，固定侧移 | 最近前沿覆盖+共用确认门限+FIFO投送 |
| weighted | 简单人员增益/距离权重 | 否 | 专门检验“简单加权”是否已足够 |
| active_only | 否 | 是 | 两因素设计的主动观测单独作用 |
| schedule_only | 是 | 否 | 两因素设计的滚动调度单独作用 |
| full | 是 | 是 | 完整方案 |
| no_prior | 是 | 是 | 取消搜索中的在线人员线索增益 |
| no_covariance | 是 | 是 | 只去掉定位协方差报告门限 |
| no_view_groups | 是 | 是 | 相邻帧也可累积证据，检验相关性问题 |

主四组构成2×2设计：调度关/开 × 主动观测关/开。所有组均采用相同检测器、定位前端、传感器、场景、载荷、速度上限和基础报告判据；仅被明确消融的部分变化。固定侧移也给出第二视角，避免把基线故意设为永远无法通过两视角门限。补充单帧立即报告可作工程参考，不能与上述同门限主比较混为一谈。

当前代码的人员增益、可见率、存在性信念和时间估计都是启发式原型。不能把其开关实验直接称为已实现完整标定的概率模型；正式实验需先补齐标定与场景采样，再冻结版本。远距离局部规划失败同样计入，不给某一方法私下加人工路标。

## 10. 评价协议与统计

独立评价器按预测报告与目标真值进行一对一距离门限匹配，默认τ=1m。重复报告不能重复计TP，多余报告为FP。应进一步做τ=0.5/1/1.5m敏感性分析。评价全过程独立，评价器只发送episode_end，不发送目标/真假判断。

| 指标 | 定义与注意事项 |
|---|---|
| 首次有效报告时间 | 从启动到首个成功匹配的合格报告；无有效报告是截止T的右删失，不能填0或只统计成功者；同时报截止时成功比例/限制平均时间 |
| 固定时间有效报告人数 | N_valid(30/60/120/300/600s)，每时刻独立一对一去重；报告轨迹，不只终点 |
| 漏报率 | FN / N_gt；所有目标与可达可观测子集分别报 |
| 误报率 | 本任务无自然TN分母，主要报FDR=FP/(TP+FP)和FP/min；无报告时FDR未定义，不填0；检测器级FPR另按固定帧标注计算 |
| 定位误差 | 匹配报告的平面RMSE/中位数/P90，注明条件分母；不能排除漏报后宣称整体定位优；增加95%椭圆实际覆盖率 |
| 物资到达时间 | 既报启动→有效投送，也报首次有效报告→有效投送；未投送右删失，同时报按期送达率 |
| 任务成功率 | 暂定所有应服务目标均有效报告并在各自期限内有效投送，且无碰撞；更严格要求还可增加无翻覆/越界，须事前固定 |

有效投送需真实车体进入目标附近1.8m、停稳至少1.5s，且有该目标的有效报告；发一条delivery消息不自动算成功。代理人仅根据自己的估计执行，评价器根据真值判定有效性，不能回传纠正。

以独立布局为统计单位，先对同布局噪声重复求指标，再做方法间配对差及布局bootstrap 95%区间；首次报告/投送同时保留删失，避免只比较成功样本。除主要指标外保存碰撞数、轨迹长度、调度耗时、卡死次数与失败原因。并行运行需隔离端口，原工具默认串行。用配置/代码/世界SHA256记录实验版本。无检出、卡死、超时和异常均不得无声删除。

## 11. 建议推进顺序与可交付证据

第一阶段：先解决人物模型/检测域差异、深度投影、里程计漂移和碰撞，完成单人无遮挡与遮挡确认预检；再验证接近与投送位置。第二阶段：冻结感知前端，加入多目标载荷冲突，完成四组主比较。第三阶段：批量生成独立测试布局、做消融与统计，保留失败视频/日志。第四阶段：如需强化学习，只替换一个已定义模块，并保留启发式方案作为基线，不同时改检测器和任务设置。

竞赛可讲述的主问题是“如何把找得到、报得准、送得到连接起来”。现阶段能交付可运行的研究原型和可审计评价，不能提前承诺性能提升，更不能把默认颜色检测的预检成绩包装为真实伤员搜索能力。
