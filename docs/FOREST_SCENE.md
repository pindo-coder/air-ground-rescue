# 大范围森林山洪场景

2026-11-17 按场景反馈更新 D：实际可探索区域从 42×30 m 扩至 **84×60 m**，车辆、人物和房屋保持原尺度。生成后的世界位于 `worlds/search_D.wbt`，配置入口为 `config/scenes/D.json`。

- **252 棵树**：22 棵替换为带纹理的阔叶/针叶树，再增加 230 棵，混合成树和幼树。Oak 与 Sassafras 使用多方向叶片树冠，低枝树布置在相机视线和林带边缘。
- **140 丛灌木**：多茎、分层弯曲叶片网格，使用带透明通道的叶片照片、法线和树皮纹理；轮廓不规则，不使用绿色球体。
- **实体起伏**：673×481 个高程点，间距 0.125 m；六处新增丘坡、浅谷、沟槽及局部细起伏。全域高程约 -0.35～7.03 m，高差约 7.38 m。地形、碰撞、物体落地高程、地图边界和评测范围同步更新。
- **材质与光照**：8K 泥土/落叶混合颜色图、4K 法线和粗糙度贴图，平衡天空光与方向光，保留树影及接触阴影。新增倒木使用树皮材质，废墟使用破损墙面材质，去掉橙色演示条纹。

森林留有树干间隙和不规则通路，枝叶主要承担视觉/深度遮挡。树干、灌木硬茎和移动障碍具有碰撞体，尚未模拟柔性枝叶受车体挤压的弯曲。

## 启动

双击仓库 `start_search_D.cmd` 或 Webots 工程目录中的 `启动复杂地形空地协同仿真.cmd`，运行真实检测与导航原型。启动器自动重建 D 世界，避免下次打开旧地图。

D 的 8K/4K 地面图与签名缓存不提交到 Git，首次启动由包内源材质自动生成并缓存；后续启动直接复用。树木模型、叶片/树皮源图、灌木模型、生成脚本与验证预览随仓库提供，运行不需要访问额外素材网站。

只看画面、重新输出高清图和检查遮挡：

也可以双击 `start_forest_preview.cmd`，或 Webots 工程目录中的 `查看森林场景渲染.cmd`。

```powershell
.venv\Scripts\python tools/render_forest_scene.py --visible --keep-open
```

此入口运行独立的静态渲染检查，不开启搜索任务。它先拍摄，再移走植被拍摄对照，随后恢复全部植被并暂停。输出 `runs/forest_render_.../` 中有：

- `overview.png`：1920×1080 大场景全景。
- `rescue_core.png`：1920×1080 救援核心区域。
- `forest_detail.png`：1920×1080 树木与灌木近景。
- `hills.png`：1920×1080 丘坡林地。
- `rover_with_trees.png` 与 `rover_without_trees.png`：相同车载相机、相同静止位姿下的植被遮挡对照。
- `depth_with_trees.npy`、`depth_without_trees.npy`、`tree_occlusion_mask.png` 和 `render_summary.json`：可复核的深度数据与结果。

所有预览来自 Webots 实际相机渲染。车载相机保留原来的 320×240、90°视场角与约 0.30 m 安装高度；仅在独立静态检查中关闭传感器噪声。高清展示相机与正常车载传感器分开。

## 遮挡检查的含义

固定出发位置，分别保留和移除所有树/灌木，比较深度：有植被时至少提前 0.25 m 返回表面的像素记作前景遮挡。当前验证约 **59% 全画面、68% 中央区域**被植被挡住，达到本次设置的 45%/50% 验收门限。中央区域为图像中央一半宽、一半高。数据来自 `runs/forest_render_20261117_172103_23688`，精确结果为 0.58544/0.68047。

该指标只说明这个固定观察位置存在实际遮挡，**不等于目标遮挡率或整个地图的平均遮挡率**。伤员识别率、导航避障与物资投送仍需单独实验；当前完整救援性能未验证。
